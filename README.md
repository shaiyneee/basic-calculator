**Name:** Shenaiah Elden B Sabana

## Project Description
The Python Basic Calculator is a simple program that
performs basic mathematical operations using two numbers.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulo
- Division-by-zero protection
- Invalid number handling

## Requirements
- Python 3

## How to Run
1. Download this repository.
2. Install Python 3 if it is not installed.
3. Open a terminal in the project folder.
4. Run `python main.py`.
5. Choose an operation from 1 to 5.
6. Enter two numbers to see the result.

## Example
Choose an operation: 1
Enter the first number: 10
Enter the second number: 5
Result: 15.0
